# bread-board-power-supply

## Project Overview
My second PCB Project (Bread-board-power-supply), designed in KiCad

## Circuit Details
- Input Voltage : 12V
- Output Voltage : 5V or 3.3V ( BY using the voltage regulators )
- Connected to LED as power indicator
- Capacitors are connected to filter noice
- Resistors are connected for adjustment and protect the components

## Tools Used
- KiCad ( version 0.10 ) : For design the board ( Schematic and PCB Layout)
- JLCPCB : To order the physical board

## Files included
- /Gerber : All gerber Files
- /pdf : Schematic File
- /png : All screenshots ( Schematic file, PCB file, Gerber file, 3D model file )
- /csv : Bill Of Materials
- /pcb : PCB Layout File
- /sch : Schematic File
- /pro : main accumulation of files
